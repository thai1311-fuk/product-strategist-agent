# Дерево возможностей и решений (Opportunity Solution Tree)

## Когда применять
- Переход от диагноза (situation.md) к вариантам: удерживает связь «желаемый результат → проблема пользователя → решение → проверка допущения».
- Когда команда пришла с готовым решением («сделаем рекомендации на ИИ») — дерево показывает, какую возможность это решение закрывает и какие ещё есть.

## Структура
```
Желаемый результат (бизнес-метрика, на которую влияет команда)
 └─ Возможность (нужда, боль, желание пользователя — из исследования)
     └─ Решение (2–3 разных на одну возможность)
         └─ Проверка допущения (быстрый тест самого рискованного допущения)
```

## Шаги
1. **Один результат вверху** — продуктовая метрика, связанная с North Star (`north-star-metric-tree.md`), а не «увеличить выручку».
2. **Возможности — только из данных:** интервью, когорты, поддержка, опросы. Каждая с [E###]. Формулировка — со стороны пользователя («не понимаю, что смотреть после первого фильма»), не решение («нет рекомендаций»).
3. **Структурируй возможности:** крупные разбивай на дочерние, пока не станет понятно, что можно решить за 1–2 цикла. Выбери **одну целевую** ветку, сравнив по: размер (сколько людей) [E###], связь с результатом, наши сильные стороны, стратегическая уместность.
4. **≥3 решения на целевую возможность**, разные по механизму (не «три варианта кнопки»).
5. **Допущения по каждому решению:** ценность (захотят ли), применимость (смогут ли), реализуемость (сможем ли сделать), жизнеспособность (окупится ли, законно ли), этика (не навредит ли). Самое рискованное и наименее доказанное — тестируй первым.
6. **Связь с этапом options:** ветви дерева на уровне **возможностей** дают содержательно разные стратегические варианты; ветви на уровне **решений** — тактические альтернативы внутри одного варианта. Не выдавай второе за первое.

## Мини-пример (пример, цифры вымышлены)
Результат: удержание 3-го месяца кино-подписки (база 39 %).
- Возможность А: «после промо не понимаю, за что плачу 199 ₽» (опрос при отмене, 41 % ответов) [E###].
  - Решения: напоминание с итогом «вы посмотрели 6 фильмов»; переход в дешёвый тариф вместо отмены; продление промо при досмотре.
- Возможность Б: «нечего смотреть после первого фильма» (интервью, 7 из 12) [E###].
  - Решения: подборки по первому фильму; сериалы как привычка; совместный просмотр в семье.
- Возможность В: «списание не прошло — подписка слетела» (недобровольный отток, 14 % отмен) [E###].
  - Решения: повтор списания; предупреждение о балансе; льготный период.
Возможности А, Б, В → разные стратегические варианты (цена/пакетирование, ценность контента, платёжная гигиена). Решения внутри ветки — тактика.

## Частые ошибки
- Возможности придуманы командой, а не найдены в исследовании.
- В узле «возможность» записано решение.
- Одно решение на возможность — нет выбора, нет сравнения.
- Дерево строится один раз и забывается — его обновляют при новых данных (`sa.py impact`).
- Тестируются лёгкие допущения вместо рискованных.
