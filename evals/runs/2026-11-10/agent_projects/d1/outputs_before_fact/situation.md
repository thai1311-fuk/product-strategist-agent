# Картина ситуации: Лингвобот — корпоративный тариф для HR

> Этап 3 synthesis. Материалы вымышленные [E003]; открытым поиском по вебу мы не пользовались, только материалы пользователя. Типы: факт = заявление источника; оценка = наш пересчёт.

## Коротко (для руководителя)
- Противоположные знаки «рынок растёт» и «рынок сократился» не противоречат друг другу: источники меряют разное (весь рынок за год против очных групповых курсов за полугодие) [C001]. Для нашего сегмента (приложения) знак не доказан.
- Цифрам отчёта верить осторожно: итог роста не сходится с составляющими [C002].
- Интерес HR есть, но по малой смещённой выборке; главный барьер — сотрудники бросают занятия [C003].
- Конкурент SpeakCorp уже продаёт тариф с отчётами для HR [C004]. Экономику B2B без продаж оценить нечем [C005].
- Пороги плана: A (рост ≥ 15 % и ≥ 5 платящих пилотов) не подтверждён ни по одной из двух частей; C и D (сегмент падает / нет интереса) тоже не подтверждены. Данные не отличают A, B, C; разумна ставка на дешёвую проверку (вариант B).
- Главный пробел: удержание, цена, затраты на ИИ и CAC (данные продукта) [E002].

Ответ: знак роста всего рынка положительный по отчёту, но величина ненадёжна [C002]. Знак по сегменту приложений не измерен; согласуется с гипотезой «очные группы падают, онлайн растёт» [C001]. Критерий «достаточно» плана (два источника с одним определением) не выполнен — записано «не сопоставимо». Искали опровержение: сверили определения и периоды обоих источников; третьего источника в материалах нет.
