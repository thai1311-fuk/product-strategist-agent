# Кейс A — ключ для судьи (агенту не показывать)

Тип задачи: диагностика по данным (почему падает метрика) → варианты действий.

## Что заложено в данных (seed 20261109)
1. Android 3.2 (обязательный вход по SMS) с 2026-09-01: доля завершивших онбординг у Android-новичков падает примерно с 0,8 до ~0,5.
2. Канал paid_promo (старт в ту же дату) хуже удерживается на обеих платформах: у прошедших онбординг удержание D7+ заметно ниже organic.
3. iOS + organic после 1 сентября почти не меняется — естественный контроль.
4. Ловушки: две причины совпали по времени; установки после ~2026-10-01 имеют неполное окно наблюдения (правое цензурирование); дубли session_start; 12 отзывов нерепрезентативны.

## Проверяемые признаки хорошего ответа (не «правильный ответ»)
- [ ] Удержание разложено хотя бы по платформе × каналу × период (до/после 1 сентября); показан вклад каждой причины, а не выбрана одна сторона спора маркетинга и продукта.
- [ ] Использована контрольная группа (iOS organic или Android до релиза) или явно описан аналог difference-in-differences.
- [ ] Отмечено неполное окно у поздних когорт (или они исключены) и дубли событий.
- [ ] Цифры удержания/онбординга имеют маркеры `[E###]`, ведущие на таблицу/расчёт в `data/` (воспроизводимый скрипт или формула).
- [ ] Отзывы использованы как иллюстрация механизма (SMS, капча, «ждал игру»), а не как доля.
- [ ] ≥3 разных варианта: например, вернуть «слушать без входа» / отложенная регистрация; изменить таргетинг или оффер кампании; оставить как есть (и цена этого); минимум один — комбинированный или с экспериментом.
- [ ] Возражения critic по существу: например, «отложенная регистрация снизит долю авторизованных → хуже рекомендации»; «урезание кампании поднимет цену привлечения органики».
- [ ] План проверки: A/B онбординга на Android (метрика, база, ожидаемый эффект, срок, нежелательное последствие — падение доли регистраций); отдельная проверка качества трафика paid_promo.
- [ ] Честные пробелы: нет данных о выручке по каналам, нет причин отказа кроме кодов ошибок, синтетическая выборка.
