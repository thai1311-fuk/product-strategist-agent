# Кейс C — ключ для судьи (агенту не показывать)

Тип задачи: коммуникационная стратегия (ценность, барьеры, сообщения, каналы, проверка).

## Проверяемые признаки хорошего ответа
- [ ] Диагноз проблемы опирается на воронку «знают (21 %) → понимают → доверяют → включили» с маркерами `[E###]` на опрос; отмечено, что основной барьер — не «не понимают ценность», а страх пропустить важный звонок и недоверие к «роботу, который слушает» (переформулировка задачи руководителя — с доказательствами).
- [ ] Ограничения опроса учтены: только пользователи приложения; 10 обращений — иллюстрации, не доли.
- [ ] Сообщения сняты с барьеров: «важные звонки не потеряются — вы увидите расшифровку / белый список», «выключить в один тап», понятный пример расшифровки; язык выгоды вместо «интеллектуальная система фильтрации».
- [ ] Найдено и исправлено недоказуемое/ложное утверждение текущей страницы: «100 % защита» противоречит feature_facts (91 % на внутреннем тесте, не защищает от номеров из контактов) → риск по 38-ФЗ. Цифра 91 % — либо не используется публично (методика не опубликована), либо с оговоркой; это решение вынесено руководителю.
- [ ] Сегменты/аудитории: например, «устал от спама», «боится за родителей» (покупатель ≠ пользователь), «боится пропустить звонки» (курьеры, врачи, работа) — с разными сообщениями и каналами.
- [ ] Согласованность с продуктом: проверка consistency-checker — коммуникация не обещает того, чего нет (мессенджеры, контакты); при необходимости — рекомендации продукту (меньше экранов, белый список, удалённое включение родителям), явно отделённые от коммуникации.
- [ ] ≥3 разных подхода к коммуникации (например, «страх/безопасность родителей», «контроль и спокойствие», «демонстрация на примере») + «оставить как есть»; critic: риск запугивания, риск усилить недоверие к записи звонков, каннибализация платных антиспам-партнёров.
- [ ] План проверки: A/B формулировок на экране в приложении или push (метрика — доля включивших и доля отключивших за 14 дней, база 6 %, срок, нежелательное последствие — рост жалоб на пропущенные звонки).

## Красные флаги
- Повтор «100 % защиты» или новые гиперболы без доказательств.
- Сообщения про «нейросети» вместо выгоды без проверки на аудитории.
- Цифра 91 % подана как публичный факт без оговорки о методике.
