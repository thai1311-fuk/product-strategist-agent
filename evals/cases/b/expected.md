# Кейс B — ключ для судьи (агенту не показывать)

Тип задачи: выход в новую аудиторию (сегментация, позиционирование, каналы, go-to-market).

## Проверяемые признаки хорошего ответа
- [ ] Рынок оценён по открытым источникам с маркерами `[E###]` (например, статистика ФНС по числу плательщиков НПД, реестр МСП, нормы 54-ФЗ о применении ККТ) — с датой данных; если источник недоступен — это пробел, а не выдуманная цифра.
- [ ] Ключевое различие учтено: самозанятые (НПД) формируют чек в приложении налоговой и, как правило, ККТ им не нужна → «касса» для них слабая ценность; ИП/малые точки с кассой — другая задача (проверяемо по 422-ФЗ о НПД и 54-ФЗ о ККТ — это факт из закона, а не мнение команды). Факт из закона помечен `fact` с цитатой; вывод о спросе — гипотеза.
- [ ] 6 встреч и 57 заявок с лендинга использованы как сигнал, а не как доля рынка; отмечено смещение (баннер в приложении «Орбиты» → аудитория — свои абоненты).
- [ ] Сегменты описаны по задаче/ситуации (JTBD), а не только по демографии; найден «разрыв» продукта — нет приёма карт для точек, где половина платит картой.
- [ ] ≥3 разных варианта: например, (1) малые офлайн-точки с 1 продавцом (кофе/выпечка) + доработка карт; (2) самозанятые — перепозиционирование на учёт/запись/приём QR без «кассы»; (3) партнёрский канал (банк/облачная касса/маркетплейс) вместо прямых продаж; (4) оставить как есть / свернуть.
- [ ] Каналы связаны с сегментом и экономикой (CAC против 490 ₽/мес), учтено ограничение на данные абонентов (согласие на рекламные рассылки — 38-ФЗ, 152-ФЗ).
- [ ] Возражения critic: каннибализация/конфликт с банками-партнёрами; доверие к оператору как к «кассе»; поддержка 24/7 для торговли.
- [ ] План проверки: пилот в 1–2 сегментах с метрикой активации (доля, принявших ≥N оплат за 2 недели), с чем сравниваем, срок, нежелательные последствия (жалобы на фискализацию).
- [ ] Вопрос о бюджете пилота задан пользователю или расчёты даны в долях.

## Красные флаги
- «Целевая аудитория — все самозанятые, их N млн» без учёта того, что касса им не нужна.
- Синтетические «интервью» с ИИ-респондентами использованы как доказательство спроса.
- Выдуманные цифры рынка без источника.
