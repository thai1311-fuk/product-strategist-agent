# Стратег Фабрики продуктов

ИИ-агент для Claude Code и Cursor, который ведёт руководителя цифрового продукта от размытого запроса («почему падает удержание?», «кому продавать?») до обоснованной **продуктовой и коммуникационной стратегии**, а после решения следит, не устарело ли оно.
Каждый вывод опирается на доказательство из реестра, а оно на источник с цитатой. Агент отделяет факты от гипотез и прогнозов, прямо пишет, чего мы не знаем, и сам считает, сколько стоила работа.
Проект сделан для MGIMO×AI Challenge, номинация «ИИ-проект», задание МегаФона «Стратег Фабрики продуктов».

**Посмотреть результат без запуска:** [`projects/<демо>/outputs/report.html`](projects/) <!-- TODO: подставить slug демо-проекта после прогона --> (откройте в браузере, работает офлайн). Описание работы: [`docs/DESCRIPTION.md`](docs/DESCRIPTION.md).

## Быстрый старт (3 шага)

1. **Клонируйте репозиторий**
   ```bash
   git clone <URL-репозитория> mgimo-strategist && cd mgimo-strategist
   python3 scripts/sa.py doctor        # проверка окружения: Python, папки, права записи
   ```
2. **Откройте папку в Claude Code** (`claude` в терминале) **или в Cursor** (File → Open Folder). Ничего настраивать не нужно: инструкции агент берёт из `AGENTS.md` / `CLAUDE.md`.
3. **Напишите агенту запрос**, например:
   > Новый проект: удержание в приложении упало на 15 % за квартал, нужно понять почему и что делать. Результат — для директора по продукту.

   Агент сам создаст проект (`sa.py new`), задаст до пяти уточняющих вопросов и предложит план исследования. Дальше он идёт по этапам и **останавливается на трёх воротах**, где решение за вами: утвердить план, выбрать вариант, утвердить стратегию.

Итог для руководителя лежит в файле **`projects/<slug>/outputs/report.html`**: решение на одной странице, варианты, стратегии, план проверки, реестр доказательств, источники, журнал действий и расходы. Чтобы получить PDF, откройте файл в браузере и выберите «Печать → Сохранить как PDF».

## Что нужно заранее

| Что | Зачем | Платно? |
|---|---|---|
| **Python 3.10+** | ядро `scripts/sa.py`; только стандартная библиотека, `pip install` не нужен | бесплатно |
| **Claude Code** *или* **Cursor** | среда, в которой работает агент | **платно**: подписка Claude Pro/Max или ключ Anthropic API для Claude Code; подписка Cursor Pro или свой ключ API для Cursor |
| **Доступ в интернет** | модель отвечает через облако; сбор открытых источников идёт только с сайтов из `config/allowed_sources.json` | — |
| Ваши материалы (по желанию) | документы, таблицы CSV, скриншоты, расшифровки интервью без персональных данных | — |

Других платных сервисов, ключей и скрытых настроек нет. Бюджет на один проект по умолчанию **5 $**: он хранится в `state.json`, а при расходе 80 % агент предупреждает. Цены моделей для расчёта заданы в `config/routing.json`; это условные цены, сверьте их с актуальным прайсом.

## Управление работой

| Вы говорите | Что происходит |
|---|---|
| «Новый проект: …» | создаётся `projects/<slug>/`, агент уточняет задачу |
| «стоп» / «пауза» | агент доделывает текущее действие, записывает точный следующий шаг и останавливается |
| «продолжи» (в том числе в **новом чате** на следующий день) | агент выполняет `sa.py resume` и продолжает с того места, где остановился. В Claude Code сводка подставляется сама (хук SessionStart) |
| «уточни задачу: …» | агент обновляет `brief.md` и возвращается только к тем этапам, которые устарели |
| «исправь вывод C004», «это неверно» | агент исправляет вывод или отзывает доказательство, затем пересматривает всё, что от него зависело |
| «новые данные: …» | агент добавляет данные, выполняет `sa.py impact`, помечает затронутые выводы как «на пересмотре» и предлагает правки |
| «что ты сделал?», «сколько стоило?» | `sa.py status`, `sa.py cost report` |
| «покажи результат» | `sa.py validate` → `sa.py report` → `outputs/report.html` |

Прогресс агент показывает строкой вида «Этап 2/8 — сбор: 7 источников, 23 доказательства, потрачено 0,42 $ из 5 $».

## Интеграции: CLI и MCP

- **CLI:** `python3 scripts/sa.py …` — работает в любой среде и в терминале.
- **MCP-сервер `strategist`** (`scripts/mcp_server.py`, только стандартная библиотека Python, stdio) — те же команды как инструменты `sa_*`. В Claude Code подключается из `.mcp.json`, в Cursor — из `.cursor/mcp.json`. Проверка без среды разработки:
  ```bash
  printf '%s\n' '{"jsonrpc":"2.0","id":1,"method":"tools/list"}' | python3 scripts/mcp_server.py
  ```
- Ворота, бюджет и список разрешённых сайтов через MCP **намеренно недоступны**: это решения человека, модель не должна менять их сама — даже под влиянием текста источника.

## Команды `scripts/sa.py`

Обычно их вызывает агент. Человеку они нужны, чтобы проверить работу или продолжить её без агента.

| Команда | Что делает |
|---|---|
| `new <slug> --title "…"` / `list` | создать проект из шаблонов / список проектов |
| `status [slug]` / `resume [slug]` | этап, следующий шаг, открытые вопросы, бюджет / сводка для нового чата |
| `stage <slug> <этап> [--status awaiting_human] [--next "…"]` | перевести этап |
| `gate <slug> plan_approved\|option_chosen\|strategy_approved [--value C005]` | отметить решение человека на воротах |
| `source add …` / `source fetch <slug> <url>` | добавить источник / скачать страницу (только из allowlist, с очисткой) |
| `evidence add\|list\|retract\|supersede …` | реестр доказательств |
| `conclusion add <slug> --statement … --depends-on E001,E002` | вывод с зависимостями |
| `impact <slug> E005\|S003` | что затронуто изменением; помечает выводы `needs_review` |
| `validate <slug>` | проверка цитирования и структуры (код выхода ≠ 0 при ошибках) |
| `decision add\|review <slug>` | записать решение / показать, что пора пересмотреть |
| `cost add\|report <slug>` / `log <slug> …` | расходы / журнал действий |
| `report <slug>` | собрать `outputs/report.html` |
| `doctor` | проверка окружения |

Полный формат команд и файлов описан в [`docs/CONTRACT.md`](docs/CONTRACT.md).

## Ключевые решения

1. **Доказательность через реестр, а не через «доверие к модели».** Источник записывается в `sources.jsonl`, утверждение с типом и дословной цитатой в `evidence.jsonl`, вывод с зависимостями в `conclusions.jsonl`. В тексте стоят маркеры `[E012]`, `[C003]`. `sa.py validate` механически проверяет, что маркеры существуют и действуют, у фактов есть цитаты, а числа подкреплены. `scripts/analysis/check_quotes.py` сверяет цитаты с текстами источников и ловит выдуманные. В отчёте при наведении на маркер видны утверждение, цитата и источник. Гипотезы, прогнозы, допущения и синтетика выделены пунктирной рамкой.
2. **Граф зависимостей для пересмотра.** Цепочка «источник → доказательства → выводы → решения» хранится явно. Когда приходят новые данные, `sa.py impact` точно показывает, какие выводы и документы затронуты, и помечает их `needs_review`, так что всё переделывать не нужно.
3. **Состояние в файлах, а не в памяти чата.** `state.json` и журналы позволяют закрыть чат, открыть новый и сказать «продолжи». Записи атомарные, у действий есть идемпотентные ключи, поэтому после сбоя видно, что уже сделано.
4. **Маршрутизация моделей ради экономии** (`config/routing.json`). Сбор и извлечение выполняет дешёвая модель (субагент collector), синтез, варианты, стратегию и критику — сильная, проверку согласованности — средняя. Если дешёвая модель ошиблась, шаг повторяется на сильной, и это записывается в журнал.
5. **Хуки Claude Code и ручной эквивалент для Cursor.** Вся логика лежит в `AGENTS.md` и Python. Хуки только автоматизируют рутину: подставляют сводку при старте, пишут журнал действий и расходы, проверяют опасные действия. В Cursor то же самое делается командами `sa.py resume`, `sa.py log`, `sa.py cost add`. Проект переносится между средами без потерь (таблица соответствия — в [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md)).
6. **Безопасность.** Тексты источников считаются данными, а не инструкциями: при сохранении они оборачиваются в `<<<SOURCE …>>>`, подозрительные фрагменты получают флаг `injection_suspected`. Скачивание идёт только по allowlist. Хук `guard.py` блокирует опасные команды и запись секретов. В репозитории нет персональных данных. В отчёте всё экранируется. Подробнее — [`docs/SECURITY.md`](docs/SECURITY.md).
7. **Меньше агентов, больше процедур.** Субагент заводится, только если даёт измеримую пользу: независимый критик, дешёвый сборщик, изолированный модельный респондент, проверка согласованности. Всё остальное — скиллы в основном контексте.

## Ограничения

- **Качество зависит от данных.** Агент работает только с открытыми источниками и материалами пользователя. Закрытых данных компаний у него нет, поэтому многие выводы о конкретном продукте остаются гипотезами, и в отчёте они так и помечены.
- **Синтетические респонденты не заменяют людей.** Ими отлаживают вопросы, но спрос и распространённость они не доказывают.
- **Валидатор проверяет форму, а не истину.** Он видит пропущенный маркер или число без источника, но не может понять, что источник ошибается. Сверка цитат выборочная.
- **Стоимость приблизительная.** В Claude Code токены считает хук по транскрипту. В Cursor расходы вносятся вручную или оцениваются (в отчёте такие записи помечены «оценка»). Цены в `config/routing.json` нужно сверять с прайсом.
- **В Cursor нет хуков и настоящих субагентов.** Роли critic и collector выполняются в основном чате по тем же инструкциям: изоляции меньше, экономии тоже.
- **Сбор из интернета ограничен allowlist.** Сайты с JavaScript-рендерингом, капчей или платным доступом не скачиваются, их материалы нужно передать файлом.
- **Окончательное решение принимает человек.** Агент рекомендует и показывает основания, но ворота за руководителем.
