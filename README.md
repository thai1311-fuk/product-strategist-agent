# Стратег Фабрики продуктов

ИИ-агент, который ведёт руководителя цифрового продукта от размытого запроса («кому продавать?», «почему не покупают?») до обоснованной **продуктовой и коммуникационной стратегии**, а после решения следит, не устарело ли оно.
Каждый вывод опирается на доказательство из реестра, а оно — на источник с дословной цитатой; факты, гипотезы и прогнозы помечены, пробелы названы, расходы посчитаны.
Работает в **любой среде**, которая читает `AGENTS.md` и запускает Python (проверено в реальной сессии только в Claude Code, остальные среды — см. «Среды» и «Ограничения»). Сделано для MGIMO×AI Challenge, номинация «ИИ-проект», задание МегаФона.

**Результат без запуска** (откройте в браузере, работает офлайн):
- полное демо (9 этапов): [`projects/esim-travel/outputs/report.html`](projects/esim-travel/outputs/report.html), описание — [`projects/esim-travel/README.md`](projects/esim-travel/README.md);
- быстрый режим по скриншотам: [`projects/ux-esim/outputs/report.html`](projects/ux-esim/outputs/report.html), описание — [`projects/ux-esim/README.md`](projects/ux-esim/README.md).

Описание работы для жюри: [`docs/DESCRIPTION.md`](docs/DESCRIPTION.md). Сценарий видео: [`docs/VIDEO_SCRIPT.md`](docs/VIDEO_SCRIPT.md). Статус внешнего аудита: [`docs/AUDIT_STATUS.md`](docs/AUDIT_STATUS.md).

## Быстрый старт

```bash
git clone https://github.com/thai1311-fuk/product-strategist-agent
cd product-strategist-agent
python3 scripts/sa.py doctor        # проверка окружения: Python, папки, права записи
claude                              # или откройте папку в другой среде (Cursor, Codex, ...)
```

Дальше напишите агенту запрос обычными словами, например:
> Новый проект: удержание в приложении упало на 15 % за квартал, нужно понять почему и что делать. Результат — для директора по продукту.

Агент создаст проект (`sa.py new`), задаст до пяти вопросов, предложит план и пойдёт по этапам. **Решения за человеком на воротах**: утвердить план, выбрать вариант, утвердить стратегию. Итог — `projects/<slug>/outputs/report.html` (для PDF: «Печать → Сохранить как PDF»).

## Требования и платные сервисы

| Что | Зачем | Платно? |
|---|---|---|
| Python 3.10+ | ядро `scripts/sa.py`, только стандартная библиотека | нет |
| Среда с моделью: Claude Code (проверена) или другая из таблицы ниже | исполняет агента | **да**: подписка или API-ключ выбранной среды/модели |
| Интернет | модель отвечает через облако; сбор — только с сайтов из `config/allowed_sources.json` | — |
| Chrome / Chromium (по желанию) | снять скриншоты страниц для UX-разбора (`--headless --screenshot`); можно прислать свои | нет |

Других платных сервисов и ключей нет. Бюджет проекта хранится в `state.json` (full — 5 $ по умолчанию, fast — 1,5 $); при 80 % агент предупреждает. **Цены моделей в `config/routing.json` условные**: сверяйте с актуальным прайсом.

## Режимы full и fast

- **full** (по умолчанию): 9 этапов, три ворота, критик и проверка согласованности. Для крупных и необратимых решений.
- **fast** («быстро и дёшево»): сбор и синтез одним шагом, 3–5 вопросов, один ворот — выбор варианта; модели cheap/medium. Пример: [`projects/ux-esim`](projects/ux-esim/README.md), около 1,6 $ по `sa.py cost report ux-esim`.
- Рекомендация режима: `python3 scripts/sa.py route <slug> "запрос" --recommend`; смена: `sa.py mode <slug> fast|full`. `option_chosen` не обходится никогда.

Режим fast добавлен после бенчмарка, показавшего, что агент в 3,5–7 раз дороже обычного чата (см. «Сравнение»).

Без хуков (все среды, кроме Claude Code) агент вызывает `sa.py session start <slug>` в начале и `sa.py session end …` в конце (в MCP — `sa_session_start/end`). Модели выбираются по уровню cheap/medium/strong из `config/routing.json`. Подробно, включая эмуляцию среды без хуков (это тест, а не запуск в IDE): [`docs/PORTABILITY.md`](docs/PORTABILITY.md).

## Команды и MCP

- **CLI:** `python3 scripts/sa.py <команда>` — `new`, `list`, `mode`, `route`, `search`, `status`, `resume`, `stage`, `gate`, `budget`, `allow`, `question`, `source`, `evidence`, `conclusion`, `impact`, `validate`, `decision`, `cost`, `session`, `log`, `report`, `doctor`. Формат файлов и команд — [`docs/CONTRACT.md`](docs/CONTRACT.md).
- **MCP-сервер `strategist`** (`scripts/mcp_server.py`, stdio, stdlib) даёт инструменты `sa_*` для большинства этих команд; проверка: `printf '%s\n' '{"jsonrpc":"2.0","id":1,"method":"tools/list"}' | python3 scripts/mcp_server.py`. Ворота, бюджет и allowlist через MCP **намеренно недоступны** (решения человека); набор инструментов покрыт `tests/test_mcp.py`. Сбор в демо шёл через эти инструменты у субагента collector.

| Вы говорите | Что происходит |
|---|---|
| «Новый проект: …» | создаётся `projects/<slug>/` |
| «стоп» | агент записывает точный следующий шаг |
| «продолжи» (в новом чате) | `sa.py resume`; в Claude Code сводка подставляется хуком |
| «исправь вывод C004», «уточни задачу» | правка и пересмотр зависимого |
| «новые данные: …» | `sa.py impact`, пересмотр по порядку |
| «сколько стоило?» | `sa.py cost report` |

## Ключевые решения

1. **Доказательность через реестр.** `sources.jsonl` → `evidence.jsonl` (тип, дословная цитата) → `conclusions.jsonl` (зависимости). `sa.py validate` проверяет маркеры `[E###]`/`[C###]` и статусы; `scripts/analysis/check_quotes.py` сверяет цитаты с текстом источников. Пример: любой отчёт, наведите на маркер.
2. **Граф зависимостей для пересмотра.** `sa.py impact` показывает затронутые выводы и помечает их `needs_review`. Пример: [`projects/esim-travel/outputs/situation.md`](projects/esim-travel/outputs/situation.md), блоки «Пересмотрено».
3. **Состояние в файлах.** `state.json` и журналы; «продолжи» в новом чате. Запись атомарная, повреждённые строки сохраняются в `.corrupt` и не теряются, ID из них не переиспользуются (`scripts/lib/store.py`, `tests/test_store_extra.py`); у записей журнала есть ключи против дублей. Это защита от сбоя при записи, а не транзакционная БД.
4. **Маршрутизация по уровням** `cheap/medium/strong` (`config/routing.json`, `scripts/route.py`).
5. **Человек на воротах.** Агент не может пройти ворота сам: `gate`, `budget`, `allow` через MCP недоступны, в Claude Code требуют подтверждения (`.claude/hooks/guard.py`), исполнитель записывается в журнал (`actor`). Внешний аудит нашёл обход ворот; он закрыт, см. [`docs/AUDIT_STATUS.md`](docs/AUDIT_STATUS.md).
6. **Безопасность:** источники — данные (`<<<SOURCE …>>>`), эвристики внедрения инструкций, allowlist, защита от записи секретов. [`docs/SECURITY.md`](docs/SECURITY.md).

### Jev и классификаторы

Jev — модель-классификатор TypeSafe (выбор из вариантов, оценка по шкале, вероятность истинности). **Мы её не подключали**: ранний доступ и платный ключ. Роль «выбрать или оценить по признакам» у нас выполняет детерминированный `scripts/route.py` (правила по ключевым словам). Интерфейс маршрутизации (`classify`, `recommend_mode`) позволяет подставить такой классификатор, но этого мы не делали и не проверяли.

### Сравнение (бенчмарк, прогон 2, 10.11)

По `evals/results.md`: **слепое преимущество агента в качестве ответа не подтвердилось** — в кейсах a и b средний балл судей выше у чата (7,9 против 7,2 и 7,9 против 6,3), в d паритет (агент 8,25 и 7,50, чат 7,50). Агент сильнее в проверяемости (сверка цитат, воспроизводимые скрипты), сохранении состояния и пересмотре в файлах (в чате пересмотр остался только в тексте). Цена: в 3,5–7 раз дороже и в 3–4 раза дольше по времени модели. Прогон 1 (9,8 против 7,45) выполнен по устаревшему протоколу и не должен использоваться как довод.

## Форматы материалов

| Формат | Как работает |
|---|---|
| Текст, Markdown, HTML, CSV | читаются и сохраняются как источники; HTML очищается; CSV анализируются скриптами |
| Скриншоты PNG/JPG | источник `kind=image`; визуальная проверка модели, утверждения привязываются к **области кадра**; пример — [`projects/ux-esim/sources/screens/description.md`](projects/ux-esim/sources/screens/description.md) |
| PDF, DOCX | не разбираются: сохраните как текст (экспорт) и подайте файлом |
| Аудио | только расшифровка (текстом); распознавания речи в проекте нет |
| Видео | только кадры-скриншоты и расшифровка; видео как таковое не обрабатывается |

## Windows

Нужен Python 3.10+ (`python` вместо `python3`, если так называется). Хуки Claude Code вызывают `python3` и shell-команды — запускайте Claude Code через Git Bash или WSL; задайте `PYTHONUTF8=1`. Конфигурация CI для Ubuntu и Windows и Python 3.10–3.13 подготовлена в [`ci/github-workflow-test.yml`](ci/github-workflow-test.yml), **но не запускалась**; под Windows мы систему не проверяли.

## Ограничения

- **Бенчмарк:** n мал (по одному прогону на кейс, для d два прогона агента); нет человека-судьи; оба судьи — модели одного семейства; рубрику и кейсы писала та же команда; кейсы выбраны не случайно; ослепление неполное. Выводы ориентировочные. Оценка «аналитик вручную» (4,5–14 ч) — экспертная оценка, не измерение.
- **Среды:** кроме Claude Code, ни одна IDE в реальности не запускалась; конфиги написаны по документации. GigaCode/Кодик — только через `AGENTS.md` и CLI, официальных данных нет.
- **Расходы:** цены моделей условные; расходы субагентов хук не видит, поэтому в части прогонов (первый прогон esim-travel) они даны оценкой и помечены `source=estimate`; в бенчмарке стоимость критика не учтена.
- **Человек в демо:** ответы руководителя S002, S003, S054 сыграл координатор, S055 вымышлен; живой человек принял только перечисленные в README демо решения.
- **Защита:** эвристики внедрения инструкций неполны (ловят известные приёмы, не гарантируют). Маскирование персональных данных — шаблонное; ФИО в свободном тексте не маскируются.
- **Валидатор** проверяет форму цитирования, а не истинность источника; сверка цитат выборочная. В `bench-d` валидатор сейчас показывает 3 ошибки (устаревшие пометки статуса в замороженном снимке бенчмарка).
- **Данные:** закрытых данных компаний нет, многие выводы о продукте остаются гипотезами; модельные респонденты спрос не доказывают; сбор из интернета только по allowlist и статические страницы.
- **Форматы:** PDF, DOCX, аудио и видео напрямую не поддерживаются (см. выше). Windows не проверялась. Jev не подключён.
- **Модели в бенчмарке:** агент работал на одной модели (sonnet), маршрутизация на сильную модель не использовалась.
- **Решение принимает человек:** агент рекомендует.
