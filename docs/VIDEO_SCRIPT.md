# Сценарий демонстрационного видео (≤ 10 минут)

**Что требует задание:** сквозной путь демонстрационного проекта — запрос, работа агента, варианты, стратегия, продолжение после перерыва.
**Как показываем:** (1) живой короткий прогон агента по брифу МегаФона в режиме fast — запрос, работа, варианты, решение человека в кадре; (2) готовый полный прогон `family-connect` по тому же брифу — стратегии, критик, пересмотр, расходы; (3) продолжение после перерыва — новый чат, «продолжи».
**Честность:** ускоренные куски подписаны «ускорено ×N», готовый прогон — «запись готового прогона 21.11». Ошибки не вырезаем.

## Подготовка (10 минут, один раз)

1. Терминал: `cd ~/mgimo-strategist && git pull && python3 scripts/sa.py doctor` — должно быть «ошибок 0».
2. Открыть в браузере (двойной клик в Finder):
   - `projects/family-connect/outputs/report.html`;
   - `projects/family-connect/outputs/brief_answer.md` (или раздел «Документ по формату заказчика» в отчёте).
3. Шрифт терминала ≥ 16 pt; уведомления выключены (Фокусирование → Не беспокоить); в кадре нет почты, ключей, личных данных.
4. Запись экрана: **Cmd + Shift + 5** → «Записать весь экран» → «Параметры» → микрофон (если говоришь голосом) → «Записать». Остановить — значок в строке меню.

### Запрос (вставить целиком на шаге 1:15)
```
Новый проект, быстро и дёшево (режим fast): бриф лежит в inputs/megafon-brief/brief.md — «Связь для близких и собственных устройств». Нужно понять, кому помочь первым, что изменить и стоит ли оператору вкладываться. Результат — для руководителя направления.
```

### Шпаргалка ответов агенту
- Спросит срок и критерий успеха → «Решение о пилоте в конце первого квартала; успех — цели из брифа».
- Спросит бюджет → «Оставь 1,5 доллара».
- Покажет варианты и рекомендацию → напечатай своими словами, например: **«Берём вариант, который ты рекомендуешь»** (если не согласен — назови другую букву). Если появится запрос разрешения на команду `gate` — нажми «Да».
- Любой другой вопрос → «Сделай как рекомендуешь».

## Если что-то пошло не так
- Агент долго работает → это нормально, в монтаже ускорить ×4–×8 и подписать.
- Агент ошибся и сам исправил → не вырезать: это плюс (видно проверки).
- Нет времени на живой прогон → показать только части 6:00–10:00 (готовый прогон + «продолжи»), но тогда «запрос» и «варианты» тоже показывать по готовому прогону: `projects/family-connect/brief.md`, `outputs/options.md`, с титром «запись готового прогона».
