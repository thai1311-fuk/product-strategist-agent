# Сценарий демонстрационного видео (≤ 10 минут)

**Цель:** за 10 минут показать путь «запрос → работа агента → варианты → стратегия → продолжение в новом чате → отчёт → новые данные и пересмотр → стоимость» и честно показать, где человек и где сыграно.
**Принцип:** зритель видит, что делает агент, на каком основании и сколько это стоит. Длинные шаги ускоряем ×4–×8 и подписываем «ускорено». Ошибки не вырезаем.
Цифры в сценарии — из файлов репозитория; перед записью сверить с `python3 scripts/sa.py cost report <slug>`.

## Подготовка

- Клон по адресу https://github.com/thai1311-fuk/product-strategist-agent; `python3 scripts/sa.py doctor` — без ошибок.
- Экран: слева Claude Code (шрифт ≥ 16 pt), справа браузер. Уведомления выключены, ключей и личных данных в кадре нет.
- Открыты заранее: `projects/esim-travel/outputs/report.html`, `projects/ux-esim/outputs/report.html`, папка `inputs/ux-esim/`.
- Для живого показа ворот создать свежий проект в режиме fast (`sa.py new demo-live --title … --mode fast`), чтобы человек нажал выбор варианта прямо в кадре. Пользователь, а не агент, вводит решение на воротах.
- Если демо-прогон дорогой по времени — показывать готовый `ux-esim` и подписывать «запись готового прогона»; не выдавать записанное за прямой эфир.
