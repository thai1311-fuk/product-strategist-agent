# Как управлять другими номерами в МТС

В приложении Мой МТС и Личном кабинете вы можете управлять всеми SIM-картами, которые использует ваша семья в телефонах, планшетах, фитнес-браслетах и других устройствах.

Для этого нужно к своему основному аккаунту привязать аккаунты ваших близких. После этого вы сможете следить за расходами, оплачивать связь, подключать и отключать услуги, настраивать тариф на всех привязанных номерах.

Есть несколько способов привязать аккаунт. Выберите удобный для вас и нажмите на него, чтобы открыть подробную инструкцию:

Способ 1. В приложении Мой МТС

1. На главном экране нажмите на значок профиля или номер телефона

2. Если в вашем аккаунте есть привязанные номера, откроется экран с их списком. Нажмите Добавить номер

Если привязанных номеров нет, откроется экран Профиля. Нажмите Добавить аккаунт

3. Нажмите Дополнительный номер

4. Выберите тип аккаунта

5. Укажите номер телефона, который вы привязываете к своему аккаунту. Нажмите Далее

6. Введите код из СМС или пароль для входа в аккаунт того номера, который вы привязываете. Нажмите Далее

7. Нажмите Да, чтобы подтвердить привязку номера

Теперь вы можете управлять всеми привязанными номерами.

Перейти к добавлению аккаунта >

Способ 2. В Личном кабинете

1. На главной странице Личного кабинета:

- с компьютера — нажмите на кнопку + рядом со своим номером под главным меню

- с телефона — нажмите на свой номер телефона

Затем нажмите Добавить аккаунт

2. Введите номер телефона, который добавляете, и нажмите Далее

3. Введите код из СМС или пароль для входа в аккаунт того номера, который вы привязываете. Нажмите Далее

4. Нажмите Да, чтобы подтвердить привязку номера

Теперь вы можете управлять всеми привязанными номерами.

Способ 3. В профиле МТС ID

1. Перейдите в раздел Связанные аккаунты

2. В поле Мобильная связь нажмите Добавить номер

3. Укажите номер телефона, который вы привязываете к своему аккаунту. Нажмите Далее

4. Введите код из СМС или пароль для входа в аккаунт того номера, который вы привязываете. Нажмите Далее

5. Нажмите Да, чтобы подтвердить привязку номера

Теперь вы можете управлять всеми привязанными номерами в приложении Мой МТС и Личном кабинете

## Как переключаться между аккаунтами

Выберите сервис, в котором вы управляете привязанным номером, и откройте подробную инструкцию:

В приложении Мой МТС

1. На главном экране нажмите на значок профиля или номер телефона:

- если вы в аккаунте основного номера

- если вы в аккаунте привязанного номера

2. Выберите нужный номер

В Личном кабинете

1. На главной странице Личного кабинета:

- с компьютера — под главным меню выберите нужный номер

- с телефона — нажмите на номер телефона

Затем выберите нужный номер
